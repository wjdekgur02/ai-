01 / 08　 ScoreLab

예측 CSV가 최종 성적이 되기까지

참가자가 제출한 한 건을 따라가며 자동 채점, 코드 검토, 최종 승인 과정을 설명합니다.

02 / 08　 참가와 접수

세 파일을 한 번에 제출합니다

참가자는 대회 코드로 가입하고 프로젝트에서 정답 열을 뺀 데이터를 받습니다.

예측 CSV, Notebook, 모델 가중치가 필수입니다. 서버는 파일 내용과 ID, 열, 행, 레이블을 검사합니다.

03 / 08　 Kaggle 실험

설비 관측 10,000건으로 고장 여부를 분류합니다

산업 데이터를 모사한 AI4I 2020 합성 데이터입니다. 고장 비율을 유지해 학습 8,000건과 평가 2,000건으로 분리했습니다.

온도·회전수·토크·마모·제품 등급을 사용했습니다. 고장 유형과 ID는 입력에서 제외했습니다.

학습셋 내부에서 고장 F1으로 결정트리를 선택한 뒤 가중치를 저장해 예측 CSV를 생성했습니다.

04 / 08　 채점 결과

정확도 99.60% · 실제 고장 68건 중 60건 탐지

정상 1,932건과 고장 60건을 맞혔습니다. 오경보는 0건이며 고장 8건을 놓쳤습니다.

모든 행을 정상으로 예측해도 정확도는 96.60%입니다. 고장 재현율은 이 기준의 0%에서 결정트리의 88.24%로 높아졌습니다.

공식 CSV 점수는 1,992 ÷ 2,000 = 0.996입니다. 이 점수는 해당 평가 분할에서 측정했습니다.

05 / 08　 마감과 횟수

마감 전 시작한 업로드는 완료 후 채점합니다

각 프로젝트에는 여러 마감과 회차별 한도를 설정합니다. 성공한 채점만 1회 차감합니다.

마감 후 신규 제출은 접수만 합니다. 필수 파일 누락이나 잘못된 레이블은 점수를 만들지 않습니다.

06 / 08　 리더보드

참가자별 최고점과 검증 상태를 함께 표시합니다

참가자 화면은 가명, 담당 관리자 화면은 실명입니다. 참가자 간 점수가 같으면 공동 순위입니다.

한 참가자의 제출 점수가 같으면 가장 최근에 수신을 완료한 기록부터 검토합니다.

07 / 08　 검토와 확정

부적합 제안은 관리자2가 승인할 때 반영합니다

관리자1은 셀 원문·로그, 가중치, 동일 예측 기록 수를 보고 의견을 남깁니다.

관리자2가 적합을 승인하면 대표 기록이 확정됩니다. 부적합을 승인하면 다음 후보로 이동하며 이미 차감된 횟수는 유지됩니다.

08 / 08　 직접 확인

제출 → 검토 제안 → 최종 승인

README의 npm run demo 명령으로 실행하세요. 참가자 계정에서 samples 폴더의 세 파일을 올려 점수와 잔여 횟수를 확인합니다.

검토 연습 프로젝트에서는 관리자1과 관리자2 계정으로 같은 제출의 판정 전후를 확인할 수 있습니다.
