Kaggle의 설비 고장 분류 과제에서 참가자가 낸 예측 파일을 따라갑니다.

01 · 제출과 접수

참가자가 세 파일을
제출합니다

정답을 제외한 평가 데이터를 받아
예측 CSV, Notebook, 모델 가중치를 올립니다.

서버는 파일 내용과 CSV의 UDI,Target 헤더,
행 ID와 레이블을 확인합니다.

마감 전에 전송을 시작하면 수신 완료 후 채점합니다. 마감 후에 시작한 제출은 접수만 합니다.

02 · 자동 채점

2,000건 중 1,992건 정답
공식 점수 0.996

학습용 8,000건으로 만든 결정트리가
평가용 2,000건의 고장 여부를 예측했습니다.

서버는 행 ID별 예측을 비공개 정답과 비교합니다.
채점이 완료되면 제출 가능 횟수가 1회 줄어듭니다.

평가셋 고장 68건 중 60건 탐지 · 미탐 8건 · 오경보 0건
Kaggle 데이터셋 · 시연 영상

03 · 추론 결과 검토

예측 CSV가 어떻게
생성됐는지 확인합니다

이 제출이 참가자의 최고점이면 익명 리더보드에
점수와 검증 상태가 표시됩니다.

관리자1은 Notebook의 학습·추론·CSV 저장 코드와 로그,
가중치 파일과 동일 예측 기록 수를 검토합니다.

관리자1이 검토 의견과 적합·부적합 판정을 제안합니다. 서버에서는 제출 코드를 실행하지 않습니다.

04 · 최종 승인

관리자2가
최종 판정을 승인합니다

적합 승인
이 제출을 참가자의 대표 기록으로 확정합니다.

부적합 승인
이 기록을 후보에서 제외하고 같은 참가자의 다음 기록을 검토합니다.

제안과 승인 이력을 저장하고 최종 성적에 반영합니다.
